# Working on this project

Conventions that are not obvious from the code, and a few rules that exist
because breaking them already cost work once.

## Language

Everything committed is in English: comments, docstrings, log and error
strings, documentation.

## No build-environment specifics in the tree

The code and the notes say what has to be in `PATH`, not how to get it there.
No package-manager invocations, no store paths, no absolute paths under a home
directory. One development environment is described in the README, in its own
section, and that is the only place for it.

## The regression is the contract

`proto/check_against_vendor.sh` compares the print filter's output against the
proprietary one byte for byte, across 77 cases. Any change to the filter must
leave it at `ALL IDENTICAL`; a diff there means compatibility broke, not that
the reference is stale.

The vendor driver is no longer installed, so the script falls back to the
SHA-256 sums in `tests/vendor-sha256.txt`, recorded while it still was. Those
sums are the only thing keeping the check meaningful — do not regenerate them
from our own output, that would just compare the filter to itself.

## Captures

Keep the raw capture of a reverse-engineering session before writing up what
it showed; a conclusion nobody can re-check is not worth much. `dumps/` is the
place, and it is ignored by git — see below for why.

**A scan carries whatever was on the glass**, and a USB dump of a scan carries
it in hex. Scan a printed test target or a blank sheet, never a document that
happens to be lying around. `proto/make_scan_target.py` generates a target
meant for this.

## What must never be committed

- **Firmware images.** The tail of the flash holds the device's TLS private
  key, its certificate, the SNMP community and the web password.
- **Verbatim extracts from the firmware** — string tables, symbol lists, the
  source paths their build left in assert strings. That is the vendor's data;
  write up what it establishes instead.
- **Decompiler output.** Same reasoning. `notes/disasm-method.md` records how
  to regenerate it.
- **Output of the vendor's filter.** It is the product of proprietary
  software; only hashes of it are tracked.
- **Anything identifying a particular unit or person** — serial numbers,
  usernames, scans of real documents.

An algorithm can be reimplemented; a table of numbers can only be copied. The
halftone mask in `src/pantum.c` is generated by our own void-and-cluster code
for exactly that reason, rather than lifted from the vendor's `.data`.

## Hardware

The device node belongs to group `lp`, so commands go through
`sg lp -c '...'`. The SANE device name changes when the printer is
re-plugged — ask `scanimage -L`, never hard-code it.

Anything that provokes an error state on the printer needs the user at the
machine: an open cover and an empty tray are safe to stage, a paper jam is
not.
